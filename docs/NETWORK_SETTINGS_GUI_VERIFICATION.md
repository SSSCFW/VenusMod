NetworkFormGameTestsを3件追加しました。通常配線・実メニューの入力によるpingと転送保持、権限/距離/閉じたメニュー/競合/モジュール抜去、Block.getDropsによる保存、Payloadの往復とデコードサイズ制限を検査します。サーバー側の模擬プレイヤーを使い、クライアントのクリックを自動操作した試験とは異なります。

126件は既存機能を含むリポジトリ全体の件数で、新規フォーム検査は3件です。通常配線の機器に対する実メニューの書き込みから、ping・転送・不正な部分更新の拒否・名前だけの編集での転送保持を確認しました。別試験で所有権、サービス公開と管理権限の分離、距離、閉じたメニュー、同時編集、モジュール抜去、実際のBlock.getDropsによる設定/装着品/故障/所有者の保存を検査し、Payloadの実バッファで往復・過大入力拒否を確認しました。

検証環境はJava21、Minecraft1.21.1、NeoForge21.1.235、Create6.0.10です。JEI/SlashBlade本体はこのGameTest環境にはなく、既存のSlashBlade実体依存検査の一部はスキップされます。任意の通常専用サーバースモークテストは今回実施しておらず、GameTestサーバーの起動・実行とは区別します。

`ci-latest` の `VenusMod-1.21.1.jar` が検証対象コミット向けに公開されたことも確認しました。公開時SHA-256: `68cb295d410a5e7da3bd2de026b1c39ffcea92dfc6810fbcb86a0d0f2484e111`。このリリースは後続の成功ビルドで上書きされます。
