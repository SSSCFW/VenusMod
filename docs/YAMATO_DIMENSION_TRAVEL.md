# 閻魔刀の次元移動

SlashBladeの魔剣「閻魔刀」をメインハンドまたはオフハンドに持ち、初期設定の **Hキー** で「次元移動」を開きます。キーはMinecraftの操作設定にあるVenusModの項目から変更できます。名前を付け替えた通常の刀は対象になりません。

## 時空裂閃（S → W → 右クリック）

閻魔刀をメインハンドに持っているときだけ、**後退キー（既定S）を押してから前進キー（既定W）を押し、その直後に使用キー（既定右クリック）**を押すと、SlashBlade Resharpedが持つ既存の「時空裂閃（Void Slash）」を発動します。別の刀、閻魔刀の名前を付けただけのアイテム、副手の刀では発動しません。

SからWまでの入力猶予は **12tick（約0.6秒）**、Wから右クリックまでは **10tick（約0.5秒）** です。Wと右クリックを同じtickに押しても発動できます。先にWを押していた場合や時間切れでは成立しません。入力が成立した右クリックだけを元の通常コンボから置き換え、他の場面では従来どおりの右クリック操作です。移動キーのバインド変更にも対応し、画面表示・装備変更・ログアウトで途中入力を破棄します。

クライアントとサーバーの双方で入力順序と猶予時間を確認し、サーバーが正規の閻魔刀を所持していることを確認した場合だけ元Modの `slashblade:void_slash` のComboStateを実行します。元Modの演出・攻撃判定を使用し、時空裂閃のモーション中は重ねて起動しません。

### 時空裂閃の一段目と拘束

`S → W → 右クリック` で発動した**閻魔刀専用の時空裂閃**は、最初の一振り（標準Void Slashの斬撃Entityが出現してから最初の6tick）でSlashBlade標準の斬撃が捕捉したMobに**固定0.5の攻撃ダメージ**を一度だけ与えます。捕捉された敵は二段目の納刀攻撃（標準Void Slashの遅延攻撃）が終了するまで、サーバーとクライアントの両方でEntity tickを停止します。移動・回転アニメーション・AI攻撃・クリーパーの爆発カウント・状態異常の進行も一時停止します。納刀攻撃のダメージと演出は元Modのままで、攻撃直後に元Modのスタンも解除します。

捕捉範囲は元ModのSlashEffect判定に一致し、一般の抜刀剣の時空裂閃には干渉しません。複数の閻魔刀使いが同じ敵を同時に拘束した場合は、最後の斬撃が終わるまで停止します。斬撃の途中消滅・Mobの死亡や退出・プレイヤーのログアウト・サーバー停止でも拘束状態を解放します。途中からMobを追跡し始めたクライアントにも停止状態を送信します。プレイヤーへの拘束は対象外で、Mobを対象とします。

## 地点の保存と整理

画面左側の「現在位置を保存」から名前を付けると、そのとき実際に立っている位置・次元・向きを保存します。保存先はプレイヤーごとに管理され、刀を持ち替えても同じ一覧を利用できます。

中央の一覧からフォルダーを開けます。地点・フォルダーの編集画面で名前変更、フォルダー間の移動、手動順序の変更、削除ができます。名前順・保存日時順・次元順にも並べ替えられます。フォルダーを削除すると中身も削除されるため、削除前に確認画面が表示されます。

## 開いた地点の履歴

開通が成功すると、出発側の裂け目を開いた位置が自動的に「履歴」へ追加されます。日時・次元・座標を確認でき、左クリックでその地点へ移動する裂け目を開けます。手動保存とは別に最新1,000件を保持し、1,001件目からは古い履歴を順に除去します。失敗や刀を持ち替えて中断した操作は記録しません。

## ランダム接続

次元移動GUI上部の **「ランダム接続」** から、半径 **1～1,000,000ブロック** の整数と「地上のみ／地上と地下もあり」を設定します。設定はプレイヤーごとに自動保存されます。目的地は現在のディメンション内で、指定した**水平距離以内**から選ばれます。既存の二振り演出で両端に裂け目を開き、帰りも同じ裂け目を使えます。

**着地点は必ず乾燥した固体ブロックの上**で、プレイヤー1体分の空間があり、足元・頭上・足場に水や溶岩がない場所です。草や花など、当たり判定がない植物は許可します。地上のみは地表の足場、地下を含む場合は安全な洞窟の床も対象です。候補は生成直前に再確認し、開通後にブロックが置かれたり液体が流れた場合も危険な位置への転送を拒否します。

広域では未生成チャンクを含むため、まず選んだ場所のチャンクを**地形生成・ブロック読み込み完了（FULL）まで読み込み**、危険なら**周囲8ブロックの各列**を調べます。必要なら隣のチャンクも読み込んで、安全な固体の足場を探索します。探索はサーバー負荷を抑えて**全プレイヤー合計で1ティックに1候補エリア**、最大48エリアを順番に検査します。裂け目を開いた後は両端のチャンクをチケットで保持し、**遠方の着地点のチャンクがEntity-ticking（エンティティ処理可能）になってから転送**します。準備中に即座に転送しようとしても失敗扱いにせず、準備完了まで待ちます。液体・空中・固体内部には転送しません。安全な場所が見つからない場合は開通を中止し、メッセージを表示します。狭い範囲や海・溶岩が広がる地域では半径を増やして試してください。

## 2地点を直接接続する

保存地点または履歴を右クリックすると始点として選択し、行に`[1]`と枠を表示します。別の地点を右クリックするとGUIを閉じ、選んだ2地点同士を接続します。保存一覧と履歴、フォルダーを跨いで選択できます。同じ地点をもう一度右クリックするか選択表示を押すと解除します。左クリックは従来どおり、自分の近くからその地点への接続です。

## 隙間を開く

中央の保存地点を左クリックするとGUIが閉じ、横から右へ、続いて上から下へ刀を振ります。刀の斬撃はSlashBlade既存のモデル・テクスチャ・描画処理を利用します。二振りが終わると目の前と保存先に対の隙間が同時に開きます。輪郭は四辺が内側に曲がるひし形で、内部にはバニラのエンドゲートウェイの描画を使います。

開通操作を始めたときの視線の向きを、上下角も含めて両端に適用します。真下を向くと床の直上に水平な面が開き、真上では頭上へ開きます。開いた後の角度は固定です。接触判定と描画で同じ向きと倍率を使用し、曲線の外側の空白部分は接触に含めません。

隙間に触れると反対側の隙間の位置へ移動します。両方向に使えますが、到着した直後はその隙間の接触範囲を一度抜けるまで再転送されません。範囲内で待ち続けるだけでは再転送は有効になりません。

裂け目は壁・床・天井などのブロックと一部または全体が重なっていても開通できます。生成時にブロックは破壊・置換しません。**保存した移動先（右クリックで選んだ始点も含む）がブロックで埋まっている場合**は、周辺でプレイヤーが立てる空間を探し、元の角度・大きさを保ったまま近くへ裂け目を移します（水平4ブロック程度、上方向最大12ブロック）。保存地点自体の座標は変更しません。近くに空間がなければ指定地点に裂け目を開き、埋まっていることを通知します。埋まった部分は通常のブロック描画や当たり判定に従い、外から見えない場合があります。ワールドの高さ制限やワールド境界外には開けません。**開通できることと通過できることは別**で、移動直前に対象の体や乗客の着地点の安全性を確認します。出口が固体で塞がれている間は転送せず、ブロックを取り除いて着地点に空間ができれば、同じ裂け目を使えます。隙間の基準は幅2.5、高さ3.2ブロックで、左側のスライダーで0.5〜5.0倍（0.1刻み）に変更できます。倍率は次に開く両端へ同時に適用されます。

## 左側の設定

| 通過対象 | 許可する対象 |
| --- | --- |
| 自分のみ | 開いた本人のみ |
| プレイヤーのみ | 全プレイヤー |
| プレイヤーと友好MOBのみ | 全プレイヤーと、敵対カテゴリ・Enemyでなく攻撃対象や怒り状態がないMOB |
| 全て | プレイヤー、MOB、落ちているアイテム、乗り物など |
| アイテムのみ | 落ちているアイテムEntityのみ |
| 経験値のみ | 経験値オーブのみ |
| アイテム+経験値のみ | 落ちているアイテムと経験値オーブのみ |

| 開放方式 | 閉じるタイミング |
| --- | --- |
| 最初の通過後 | 最初の1体が通過してから指定秒後 |
| 指定時間 | 隙間の生成から指定秒後 |
| 無制限 | GUIから閉じるまで |

秒数は1〜180秒です。初期設定は「自分のみ」「最初の通過から1秒後」です。**「設定を適用」ボタンは不要で、選択肢の変更は自動保存されます。** 秒数入力中・倍率スライダー操作中は連続送信を避けるため少し待って最後の値を保存します。GUIを閉じたり地点を選んで開通するときには未送信の有効な値を即時確定し、開通要求にも設定を含めるため、保存応答を待たずに開けても直前に選んだ閉鎖条件が使われます。秒数が空欄・範囲外の場合は正しい値へ直してから開通してください。後続の通過で終了時刻が延長されることはありません。時間になると転送判定を無効にし、短く縮んで両側とも消えます。**設定変更は新たに開く裂け目に適用されます。既に開いている裂け目は生成時の閉じる条件を維持するため、変更したい場合は一度閉じて開き直してください。**

## 開いている隙間の管理

中央の「開いている裂け目」タブから生成済みの対、出発側と到着側の位置、残り時間を確認できます。個別に閉じる操作と、全て閉じる操作があります。どちらの操作でも対の両側が閉じます。

保存地点・フォルダー・履歴・設定・開いている対・到着直後の再転送防止状態はワールドに保存され、再起動後も引き継がれます。保存地点とフォルダーは合計2,048件、履歴は別枠で1,000件、開放中の対は1人64組までです。旧版で開いていた対は縦向き・1倍として読み込みます。クライアントとサーバーは同じ新版JARを使用してください。

## 検証方法

`gradle build` に、整理規則、画面配置、曲線と斜め方向の接触、寿命、到着ロックの回帰検査を含めています。既存のGitHub Actionsでは続いて `gradle runGameTestServer -PvenusTestCreate=true` を実行し、Minecraftの実Entity・SavedData・通信コーデックを検査します。

GUIの実操作、刀の一人称・三人称モーション、描画最適化Modやシェーダーと組み合わせた表示は、これらの自動検査とは別にMinecraftクライアントで確認する項目です。
