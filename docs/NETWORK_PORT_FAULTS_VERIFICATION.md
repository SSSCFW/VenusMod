## 失敗先行と純Java

公開CLI `port 0 fault`が未対応で失敗、新しい物理故障モデルが存在せずコンパイル失敗、共通ガイドに操作例がなく失敗することを確認してから実装しました。

合計111検査。全86個のネットワーク純JavaテストクラスをJava21で再コンパイル・実行して成功しました。抽選の乱数はモデル試験で決定的な値を渡し、機器/ポートの選択・完全安定化・管理OFF・候補なし等を確認しています。実サーバー上で確率頻度を統計測定したという意味ではありません。

通信試験は公開コマンド→実際のリンク成立判定を使い、故障ポートの拒否、正常なポート対の到達性、独立物理網の転送保持、simple STPの迂回、enable/モジュール交換/フォーム編集による無料修理の防止を確認します。

旧v14 fixtureは変更前の実クラスで生成した固定文字列です。v15のポート故障を全8機種で往復し、未知の故障ビット・切断・余分な保存データの拒否を検査しました。既存試験は現在書出し形式の期待値のみv15へ変更し、旧fixtureと個別の設定値検査を残しています。Syslog severity/NTP drift/許可VLANの破損検査は、新しい末尾1byteを考慮して元の対象を壊すようにしています。

アセット生成・参照検査は1,594 JSON・204 PNGで成功。画像・モデル・レシピ生成器は無変更です。既存ガイドの22トピック93手順を維持しています。
