## 失敗確認・ローカルJava21

公開CLI `ntp server on` が未対応で失敗すること、新しい4時刻/時計APIとSyslogの固定時刻フィールドが未実装でコンパイルに失敗すること、共通ガイドの欠落を確認してから実装しました。

| NtpNetworkTest | UDP/経路/NAT/ACL42検査成功 |
| NtpLimitsTest | 予約・公平性・上限10検査成功 |
| NtpCodecTest | 旧v12・v13保存・入力32検査成功 |
| NtpSyslogTest | 記録時刻の不変性5検査成功 |
| NtpGuideTest | 図・本文16検査成功 |

合計147検査。大量クライアントの登録やtickの反復数を独立検査数に数えていません。旧v12 fixtureは変更前の実クラスを動かして取得した固定文字列です。既存保存テストは現行ヘッダー期待値とSyslogフィールドの破損位置を新しい末尾節に対応させ、旧データと内容検査を維持しています。過去のガイド件数はNTPページだけを除いた従来件数を検査します。

既存を含む75個の純Javaテストクラスを再コンパイル・実行して全て成功。アセット生成・検査は1,594 JSON / 204 PNG、全参照解決。画像・モデル生成器とレシピは変更していません。

全シミュレーターへLong.MAX_VALUEを追加する試験は、NTP到達前に既存STPの加算オーバーフロー検査で失敗しました。無関係なSTPを変更せず、結合の時間飛び検査は10億tickとし、過去分を一気に処理しないことを確認しています。任意のlong時刻への全機能対応を保証しません。
