# 診断GUIから転送を操作する

機器の「診断」→「転送操作」を開きます。JEIなしでも使えます。「転送一覧」で自機の転送IDを確認し、ID欄に `12` または `#12` のように入力します。一覧は手動更新で、自動ポーリングは行いません。

## 優先度と停止

`low / normal / high` のボタンで相対優先度を選び、「優先度変更」で送信します。宛先・転送量の入力は不要です。これは選んだ1本の転送の重みを変えるだけで、機器のポート速度・ケーブル・WAN上限を上げません。転送開始用の優先度とは別に保持します。

「転送停止」を押した段階では **未送信** です。表示されたIDを確認し、「停止を確定」を押すと既存サーバーへ停止要求を送ります。「確認を中止」では転送を止めません。停止確認後は10クライアントtickの連打抑制があり、即座の二重クリックで確定しません。サーバー側の操作制限はこれと別です。

IDや操作優先度の編集、ページ移動、ガイドへ移動、リサイズで停止確認を取り消します。入力途中のIDと優先度は同じGUIの中では保持しますが、GUIを閉じて開き直すと初期状態になります。リサイズだけで停止要求を送ることはありません。

## 結果・権限

「送信」表示は要求を送っただけで、成功ではありません。結果欄は従来どおり最後のサーバー表示です。新しい応答が届くまでは前回結果が残ります。不正IDは未送信となり、結果を成功表示へ書き換えません。IDは正のlong範囲で検査し、改行・複数命令・小数・負数・範囲外の整数は拒否します。

操作できるのは現在開いている機器が送信元の転送だけです。他の送信元、権限外、閉じたメニューからの要求は、既存のサーバー認可で拒否します。対象が完了済み・停止済みなら見つからない旨を返し、別の転送を代わりに操作しません。停止によるNAT変換の扱いは従来どおりで、共有表を直接削除しません。

## ガイドと互換性

機器内とJEI共通の基本設定ガイドに転送操作・停止確認の説明を追加しています。既存23トピック97手順は保持し、JEIカードは実フォントで必要に応じて分割します。画面内の説明検索も追加文を対象にします。

保存v16・通信network-3、136種の4/16幅ケーブル、画像/モデル/レシピ、ネットワークの帯域配分や認可を変更していません。実ファイル・OS・外部ネットワークは操作しません。クライアントとサーバーは同じMOD版を使用してください。
