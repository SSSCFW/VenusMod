# VRRP広告・タイマー 検証記録

## ローカルで実行した検査

Java21で新旧のネットワーク検査を再コンパイルし実行しました。VRRPの初回結合試験は、変更前に10ケース中8ケースが即時選出や未実装コマンドで失敗することを確認しています。

| 検査 | 結果 |
| --- | --- |
| VRRP状態機械 | 31項目成功 |
| VRRP実通信との結合 | 53項目成功、失敗0 |
| VLAN・一方向広告・NAPT等の境界 | 29項目成功 |
| 保存互換性・設定検証 | 14項目成功 |
| 既存の基本・回帰 | 49項目・28項目成功 |
| ACL・DHCP・保存 | 162項目成功 |
| NAT各種 | 182項目成功 |
| OSPF | エンジン22・結合36・コマンド/公開契約成功 |
| ガイド | 13トピック・123項目成功、46手順 |
| 要求上限 | 10,009アサーション成功 |
| 既存アセット | 174 JSON・74 PNG、全参照解決 |

新しいVRRPの検査は合計127項目です。状態機械の検査では500回の広告受信後も期限が1件のままであることを確認していますが、これを500件の独立試験とは数えていません。要求上限の10,009回には上限到達後の反復拒否確認を含み、性能計測ではありません。

基本検査の既存VIP試験は、即時選出を期待するものから、起動/故障直後に通信できず期限後に引き継ぐという要件へ更新しました。旧v4保存入力は変更前の実コードで生成した固定fixtureを使用し、旧VIP・故障・名称を維持することを確認しています。不適合な旧VIPを捨てて設定全体を初期化せず、VRRPだけ稼働不可にします。

## 実ブロック試験とCI

NetworkVrrpGameTestsを2件追加しました。通常のケーブル配線とサーバーtickによる起動待ち、故障後の待機、引継ぎ、preempt off/on、広告分断の競合、復旧を検査します。別の試験ではBlock.getDropsを使ってVRRP設定、モジュール、所有権、故障の機器アイテム保存を検査します。

検証対象コミット: **`f8a46942ba0bf4dc26fa2063378626e6877c5323`**。
[Build 1.21.1 NeoForge / run 39048231055](https://github.com/SSSCFW/VenusMod/actions/runs/39048231055) の完了結果とダウンロードした診断ログを確認しました。

| CI検証 | 結果 |
| --- | --- |
| 全体ビルド・check | 成功 |
| Native GameTests with Create | **必須113件すべて成功** |
| JAR内機器説明検査 | 成功 |
| JAR準備・公開 | 成功 |
| CI入力とローカルの照合 | 今回の変更26ファイルすべてバイト一致 |

113件は既存機能を含むリポジトリ全体の件数です。今回の新規VRRP試験は2件で、テストから論理リンクやMaster役割を注入せず、通常のブロック配線とサーバーtickを使います。機器所有権の検査はサーバー側の模擬プレイヤーによるもので、実際の複数人の画面操作とは区別します。

検証環境: Java21、Minecraft1.21.1、NeoForge21.1.235、Create6.0.10。JEI/SlashBlade本体はこのGameTest環境にはなく、既存のSlashBlade実体依存検査の一部はスキップされています。任意の通常専用サーバースモークテストは実行しておらず、GameTestサーバーの起動・実行とは別です。

`ci-latest` の `VenusMod-1.21.1.jar` が検証対象コミット向けに公開されたことも確認しました。公開時SHA-256: `9fbd03ebc931b5b6d64e4fd4c32f1edaab61ec693a16ec95c2a3380273c584af`。このリリースは後続の成功ビルドで上書きされます。

## 未実施・範囲

実クライアント目視、JEI実操作、シェーダー併用、複数プレイヤーの実操作、大規模TPS測定は未実施です。独立したレビュー用サブエージェントがないため、今回は自己レビューとテストで検査しています。

IPv4・1機器1VIP/1VRID、優先度1〜254のゲーム内実装です。IPv6、複数グループ同居、owner優先度255、NAT状態同期、完全なワイヤ形式は未対応。物理配線変更時のディメンション単位のトポロジー再構築・未ロード区間の中継などの制限は [NETWORK_VRRP.md](NETWORK_VRRP.md) を参照してください。細いケーブルと既存テクスチャ・レシピは変更していません。
