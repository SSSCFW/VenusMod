144件は既存機能を含むリポジトリ全体の件数で、新規のトランクGameTestは2件です。青色ケーブルで通常配線した2つのVLANについて、送信側と受信側の許可リスト、物理リンクを維持したままの通信遮断、不正リストの拒否、再許可後の復旧を検査しました。別試験では実メニューとFakePlayerによる所有者操作、サービス公開によって管理権限を取得できないこと、古い画面からの同時編集拒否、閉じたメニューからの入力拒否を確認しました。Block.getDropsによる実際の機器ドロップから、許可リスト・装着品・故障・所有権の復元も確認しています。論理リンクや成功結果を直接注入した試験ではありません。

再開時には、このCIの診断アセットに同梱されたnetwork-test-inputs.zipを新しい検証用ディレクトリへ展開し、Java21でcoreとtests/networkを再コンパイルしました。**81個の純Javaテストクラスすべてが成功**し、トランク関連6クラスの**97検査**も再実行して成功しました。アセット生成器も再コンパイルし、**1,594 JSON・204 PNGの全参照解決**を再確認しました。コンテナ内でMOD全体を再ビルドしたという意味ではなく、全体ビルド・ネイティブ試験は上記CIの完了結果に基づきます。
