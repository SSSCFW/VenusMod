# 静的経路の設定GUI

ルーター/L3スイッチの通常コンソール左下「経路設定」を開きます。JEIは不要です。PCなど経路転送機能を持たない機器では編集できません。

## 追加と一覧

宛先を `10.20.0.0/24`、次ホップを `192.168.2.2`、出力ポートを実際に配線した面（P0北/P1東/P2南/P3西/P4上/P5下）に指定し、「経路を追加」を押します。入力だけ・ページ表示だけでは送信しません。`10.20.0.42/24` のホスト部は落とし `10.20.0.0/24` として扱います。`/0`は既定経路、`/32`は単一ホストです。

「静的経路一覧」は登録済みの静的設定だけを手動で表示します。OSPF/BGPの学習経路を編集するものではありません。設定を保存できても、次ホップへ届く・指定ポートが稼働中・返送経路があるとは限りません。診断GUIのPing/経路確認で往復を確認してください。

## 確認付き個別削除

削除する宛先・次ホップ・ポートを入力し「個別削除」を押すと、正規化した対象を表示します。この時点は未送信です。「削除を確定」で初めて要求を送ります。「確認を中止」、入力編集、ガイド/ページ移動、リサイズでは確認を取り消します。下書きの宛先/次ホップ/ポートは同じGUI内で保持します。GUIを閉じた後の保存ではありません。

同じ宛先でも次ホップやポートが違う経路は残します。旧ワールドのホスト部付き・重複した設定は意味が同じ組をまとめて削除します。全消去ボタンはありません。従来の `route clear` はCLIで引き続き利用できます。

```text
route add 10.20.0.0/24 via 192.168.2.2 port 1
route delete 10.20.0.0/24 via 192.168.2.2 port 1
routes
```

同じ意味の経路を追加しても重複を増やしません。未存在経路の削除、誤入力、同値追加では通信を再初期化しません。実際に経路を変更すると、その物理網の転送やNATを再確立する場合があります。静的経路の上限は64件です。

## 権限・結果・説明

既存のCommand Payloadとサーバー側の所有/共有権限、メニュー有効性、距離、レート上限を使います。他の機器の設定を直接書き換えたり、外部IPへOSからアクセスしたりはしません。送信表示は要求送出だけを意味し、結果欄はCLIと共有する最後のサーバー表示です。新応答が届くまでは前回の結果を含みます。

ガイドのルーティングページとJEIの同じページへ、設定例・正規化・削除確認・戻り経路の説明を追記しています。元の23トピック97手順を維持します。検索索引も同じ説明を使用します。

保存v16・通信network-3、136種の4/16幅ケーブル、画像・モデル・レシピ・装着品/故障/所有権の保持仕様は変更しません。経路設定は通常の機器保存・採掘/再設置で引き継ぎます。削除確認やGUI下書きは保存しません。
