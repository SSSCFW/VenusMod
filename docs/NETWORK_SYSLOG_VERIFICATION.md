# Syslog集中収集 検証記録

開始点: `a931c2d`。ローカル入力は既存CI `6e62c27` のテスト入力スナップショットで、開始点までの差は検証文書のみです。

## 失敗確認とローカルJava21

公開CLIの`syslog server on`が未対応で失敗することを確認後に実装しました。共通ガイドも欠落による失敗を確認してから追加しました。

| 検査 | 結果 |
| --- | --- |
| SyslogContractTest: 公開CLI・非同期収集・severity | 32検査成功 |
| SyslogNetworkTest: 一方向・NAT・ACL・故障・独立LAN | 20検査成功 |
| SyslogLimitsTest: 受付/配送/履歴上限・公平性・再帰防止 | 20検査成功 |
| SyslogCodecTest: 旧v8の固定入力・v9往復・不正CLI・転送保持 | 27検査成功 |
| SyslogGuideTest: 図・手順・既存アイコン | 16検査成功 |

新規は合計115検査です。ログ1000件の大量発生や履歴4096件の反復保持などは1件の条件検査として数え、繰り返したログ数を独立検査数に加えていません。

旧v8 fixtureは、変更前の実クラスを実行して生成した固定文字列です。既存保存テストの期待ヘッダーだけをv9へ更新し、旧版移行・OSPF/BGP・DNS等の値の検査は維持しています。既存DNS・フォームガイドの固定件数は今回のSyslogページを除いた件数で確認し、以前の内容を残しています。

48個の純Javaテスト実行クラスを再コンパイル・実行して成功しました。既存ACL/DHCP/DNS、NAT、OSPF/BGP、STP/VRRP、局所配線、フォームGUI・要求上限を含みます。アセット生成・参照検査は174 JSON・74 PNGで成功し、画像/モデル生成器とレシピは変更していません。

## ネイティブとCI

`NetworkSyslogGameTests`を2件追加しています。通常のブロック配線とサーバーtickによる片方向収集、NAPT後の送信元IP、既存pingの自動ログ収集、UDP514のACL、実断線/再配線と、機器ドロップへの設定/装着品/故障/所有権保存、権限外の履歴消去拒否を検査します。論理リンクや受信履歴は直接注入しません。

**この文書の初回作成時点では、今回の全体ビルドと新規GameTestの結果は未確認です。** 既存のBuild 1.21.1 NeoForgeで該当コミットを検証して追記します。

## 範囲・未実施

自己レビューと試験を実施。独立したレビュー用サブエージェントは使用していません。実クライアント目視、追加ログボタンのクリック、JEI画面、シェーダー、実際の複数人操作、大規模TPS測定は未実施です。模擬プレイヤーの認可検査を実際の2人のGUI操作と混同しません。
