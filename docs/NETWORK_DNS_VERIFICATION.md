## 基準と失敗再現

開始点は756a996、コード入力は7f89456の既存CIスナップショットです。開始点までのコード変更はなく、READMEと検証文書だけが異なります。

変更前の公開APIで、旧DNS照会は成功、名前でのping・転送/TTL/複数回答/停止設定/キャッシュ表示の5ケースは失敗することを確認しました。続いて「DNSだけの変更で転送を切らない」「DNSサーバーを別値へ変更して戻した場合に旧キャッシュを再利用しない」「欠けたset/ttl/list構文を旧CLIの名前と誤解釈しない」を失敗試験で再現し、修正しました。
