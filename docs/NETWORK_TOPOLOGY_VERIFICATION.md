# 局所配線・通信保持の検証記録

## 実行済み（ローカルJava21）

基準はSTP実装 `7f69771` の既存CIソーススナップショット。リモート開始点 `36903bf` との差は検証文書のみです。

- 変更前に、別物理網の断線・端点追加/削除・設定変更・STP/VRRP遷移で正常な転送/NATが失効する6ケースを再現しました。
- `TopologyIsolationTest`: 63検査成功。NATエントリー、実転送、OSPF学習経路、STP/VRRP変化、結合/分割、不正CLI拒否を検査。
- `CableTopologyTest`: 638検査成功。通常/分岐/異種/長さ/途中再編集/ロード/端点交換/反復編集。多くは予算内の各tick処理の反復確認で、638種類の独立ケースではありません。
- `CableTopologyFuzzTest`: 1,500回の固定seed編集に対し、独立した全走査オラクルと600回の接続/索引照合に成功。
- `CableTopologyScaleTest`: 12検査成功。1,000区間/5,000ケーブル、切断17・修復18作業単位、無関係な区間の参照なし。TPS計測ではありません。
- 既存ネットワーク検査一式を再コンパイル・実行。OSPF、NAT、VRRP、STP、ACL/DHCP、保存互換、要求上限の検査を保持。
- JDKアセット生成/検査: 174 JSON・74 PNG、全参照解決。ケーブルのモデルと画像の変更はなし。

索引クラス未実装でのコンパイル失敗と、既存コードでの局所性の機能失敗を区別しています。不正CLIによる接続失効も追加の失敗試験で確認してから修正しました。
