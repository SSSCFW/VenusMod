# 金星ディメンション — 初回実装

対象: Minecraft 1.21.1 / NeoForge。既存の `feature/venus-hostile-mobs` に追加する。

## 入口と帰還

金ブロックで縦向きの枠を作り、枠の内側に火打石と打ち金を使用する。
最小内寸は幅2×高さ3、外寸4×5。四隅は省略可能で最少10個の金ブロック。
内寸は幅2〜21、高さ3〜21。X/Z方向の両方に対応する。金インゴットや金鉱石は枠にならない。

ポータル面は16フレームの金色アニメーション。金色の粒子を出し、紫色のバニラ画面オーバーレイは使用しない。
サバイバルのプレイヤーは80tick、クリエイティブは1tick滞在すると移動する。
オーバーワールドと `venusmod:venus` の間のみで利用可能。ネザー・エンドには接続しない。
座標スケールは1:1。リンクをオーバーワールドのSavedDataに保存し、再起動・他プレイヤーの利用後も対になる入口に戻す。
枠の必須部分が壊れると閉じる。無効になった保存先は再検査する。

未接続の既設ゲートを近距離から探し、なければ移動先に金枠と照明付きの足場を生成する。
既存の固体ブロック・コンテナ・液体を破壊してゲートを作ることはしない。
地表で十分な平地を確保できない場合は空中足場を使うため、周辺探索用のブロックを持参すること。
安全な移動先がない場合や大型Entityが収まらない場合は移動を中止する。

## 地形・ニッケル

金星の荒野 `venusmod:venus_wastes` を追加。黄土色の地表・空・霧、洞窟、深層岩、低地の溶岩を持つ。
固定時刻18000。雨は降らず、地上でも敵対Mobが湧く。ベッドは使用可能。
熱・気圧・酸素による追加ダメージは今回の範囲に含めない。

ニッケル鉱石は金星の地下にのみ自然生成する。設定はY=-60〜112、18回/チャンク、鉱脈サイズ9。
地形・置換可能な石の有無によって実際の個数は変わる。石には通常ニッケル鉱石、深層岩には深層ニッケル鉱石が入る。
既存の精錬・幸運・シルクタッチ・金属分離機のレシピは変更しない。
これにより、旧PR説明の「自然生成なし」はこの追加以降は該当しない。

## 地上スポーンの3倍の定義

金星のMONSTERカテゴリについて、バニラのスポーン処理1回に加え、地表候補のみ許可する追加処理を2回実施する。
通常5種類の金星Mobをバイオームの自然スポーン表に設定する。
すべての候補でブロック光0を要求するため、松明などで照らせば湧きつぶせる。
バニラの距離・衝突・難易度・Mob上限・ローカル上限を維持する。他ディメンションや洞窟向けの試行数は増やさない。

**3倍は上限到達前の地表スポーン試行機会の倍率であり、実測出現数や同時存在数が常に3倍になる保証ではない。**
Mob上限は変更していない。上限まで3倍にする変更や大型の独自スポーン管理機構は今回入れていない。
Mixinは自然スポーンの該当呼び出しだけを対象とする。他Modが同じ呼び出しをRedirectする場合の競合は要検証。

## 金星要塞と最初のボス

構造物ID: `venusmod:venus_citadel`
金星のみに生成する31×16×51の要塞。構造物セットはspacing40 / separation12チャンク。
これは配置候補の間隔であり、必ず40チャンクごとに一つ生成する意味ではない。

入口階段 → 中央通路 → 左右の戦闘部屋 → 床罠・宝箱の部屋 → レバー式鉄扉 → 守護者の間。
左右4部屋、2個の金星Mobスポナー、2個の戦利品チェストを持つ。
扉の開放には外部Modの機械や新素材は不要。ブロック破壊による攻略を禁止する保護機能は入れていない。

最奥の祭壇に近づくと専用Entity `venusmod:venus_guardian` を一度出現させ、祭壇は通常の金ブロックに変わる。
ピースフルでは召喚しない。召喚済みの守護者は消滅せず、ピースフル中は攻撃を停止する。
金星の守護者: 体力300、基本近接攻撃力18、防御12、ノックバック耐性100%。
専用の黄色ボスバーと、半径6の予告付き衝撃波（基本ダメージ14、160tickの再使用間隔）を持つ。
通常金星ゾンビとは別EntityTypeだが、今回の外見は既存の金色ゾンビモデル/テクスチャを再利用する。

報酬は新アイテム `venusmod:venus_core`（金星核）1個、ニッケルインゴット4〜8個、金インゴット4〜8個。
金星核を消費する上位機械・装備のレシピ、複数ボスによる進行解放、独自ボスモデルは未実装。
守護者のスポーンエッグと金星核はVenusModクリエイティブタブにも追加する。

管理者用の探索コマンド:

```mcfunction
/execute in venusmod:venus run locate structure venusmod:venus_citadel
```

## アセットの生成

`tools/java/VenusAssetGenerator.java` はJDK標準ライブラリだけで金色ポータル画像・金星核画像・要塞NBTを生成する。
Gradleの `processResources` が `generateVenusAssets` を呼び、`build/generated/venusAssets` の成果物をJARに含める。
通常ビルドにPythonは不要。アセット生成器のJavaコンパイルと実行は単独で確認済み。

## 検証結果と次の確認

この変更作成時に実行済み:

```sh
javac -d /tmp/venus-tests src/main/java/dev/ssscfw/venusmod/world/PortalRectangle.java tests/PortalRectangleTest.java
java -cp /tmp/venus-tests PortalRectangleTest
python tools/validate_venus_resources.py
```

純粋Javaの枠検査2,745件に成功。22個の追加・編集JSONの構文と主要参照、画像サイズ、NBTの19,067ブロック、4部屋とボス部屋への床上経路、Java製アセット生成器のコンパイル・実行・再生成の一致を検査した。
床上経路検査は鉄扉が開いていると仮定した静的検査であり、ゲーム内のレッドストーンやAI経路検査ではない。

**Minecraft/NeoForge全体のJavaビルド、Codecによるワールド読込、Mixin適用、クライアント描画、実際の往復・戦闘は未検証。ビルド済みJARを保証する状態ではない。**
実行環境ではJava21単体を使用できたが、GradleとMinecraft/NeoForge依存関係を取得できなかった。
既存GitHub Actions「Build 1.21.1 NeoForge」は手動実行方式なので、対象ブランチを指定して実行する。
`server_smoke_test` も有効にして、データパックと専用サーバーの起動を確認する。

実機確認では最小枠・四隅省略・最大枠・両方向・不正枠、枠破壊、往復、再起動、複数入口/プレイヤー、帰還先の閉塞、松明での湧きつぶし、要塞の鉄扉と祭壇・ボス撃破後の再起動を確認する。
既存ワールドに導入する際はバックアップを取り、ゲーム/サーバーを再起動する。鉱石と要塞の自然生成は新規生成チャンクが対象。

## 金星刀鍛錬機と個別強化

Create + SlashBlade導入時に `venusmod:venus_blade_forge`（金星刀鍛錬機）を追加する。64 RPM以上で稼働し、手に持った抜刀剣を1回の操作につき1レベルだけ強化する。
スニーク右クリックで強化項目を順番に選択し、通常右クリックで選択中の項目を強化する。空手で通常右クリックすると現在の項目と次レベルの必要素材を表示する。

強化は刀ごとのCUSTOM_DATAに保存し、項目ごとに独立する。上限は固定し、上限超過は不可能。

- 斬撃威力: 最大Lv10。1レベルにつき直接斬撃の生ダメージ+1.5（最大+15）。
- 幻影剣威力: 最大Lv10。1レベルにつき幻影剣の生ダメージ+1（最大+10）。
- 集中ランク獲得: 最大Lv5。SlashBlade本来の獲得量に1レベルにつき+10%（最大+50%）。
- 耐久効率: 最大Lv5。耐久消費を1レベルにつき長期平均10%軽減（最大50%）。端数は刀側に蓄積し、1ダメージ単位の消費でも偏らない。
- 金星特効: 最大Lv5。金星ディメンション内の与ダメージを1レベルにつき+5%（最大1.25倍）。

すべての強化には金星核の所持が必要だが消費しない。上位レベルは金星魂石も所持条件となるが消費しない。
消費素材は耐圧合金・ニッケル・ヴェネサイト・硫黄で、各項目のレベルが上がるほど必要総数が必ず増える。高レベルほどヴェネサイトや耐圧合金の比重も上がる。
これによりボス進行キーを失って次のダンジョンへ進めなくなる循環依存を避ける。
