# JEIのネットワーク仕様カードと接続ガイド

Minecraft1.21.1 / NeoForge。JEIは任意で、未導入でも従来の機器GUI内ガイドは使えます。検証に使う版はJEI19.21.0.247です。

## 使い方

JEIのアイテム一覧またはインベントリでネットワーク機器・ケーブル・部品を選び、**用途表示（既定U）**を開きます。

- **ネットワーク機器・配線の仕様:** 最大帯域・最大長・接続条件、ポート/本体/WANの装着枠、修理・故障・共有の注意点。
- **ネットワーク接続ガイド:** そのアイテムに関係する接続図と操作手順。図中の機器アイコンも通常のJEIアイテムとして調べられます。

実際のクラフト材料と完成数は、**レシピ表示（既定R）**で確認してください。仕様カード・接続図は説明であり、アイテムを消費したり自動配置・自動設定したりするレシピではありません。レシピ転送の「＋」を登録していません。

ネットワーク診断ツールは両カテゴリ全体への入口です。機器GUIの通常コンソール右下にも、JEI導入時だけ「JEI」領域を表示します。クリックすると両カテゴリを開きます。設定フォーム・内蔵ガイドの表示中はこのクリック領域を無効にし、背後の画面へ反応させません。

## 色付きケーブルと強化アイテム

無染色＋16色の全136ケーブルを規格別に索引化しています。例えば青色Cat6Aからも、そのCat6Aの仕様とLAN接続手順を検索できます。色で速度を変えたり、異なる規格・色を直接接続可能にしたりはしません。

ケーブル8規格、機器8種、部品18種、ゴーグル2種の**36仕様**を用意します。合計164アイテムを対象とし、Create未導入時は統合ゴーグルの仕様を登録しません（その場合35仕様・163アイテム）。ポートモジュールからは光配線と強化、WANモジュールからはWANと強化などの関連手順を辿れます。

以前の全アイテム共通の長いCLI一覧ではなく、そのアイテムの役割・必要条件・制限を説明します。通常機器を全ガイドの触媒にする登録を外し、どの機器を選んでも全手順が出る状態を避けます。

## 長文と表示

既存の23トピック・97手順を削除せず、Minecraftの実フォントで折り返して本文8行ごとに「続き」のカードへ分割します。表示カード数はフォントと言語で変わります。長いDHCP設定例や日本語説明を下端で切り捨てません。

見出しが横幅を超える場合は表示を短くし、カーソルを重ねると完全な見出しを表示します。図は静的な概念図で、Create Ponderの3Dアニメーションではありません。既存のテクスチャ付き機器アイコンを使います。

## 開発検証

通常はJEIを実行依存にしません。開発クライアントへ実体を入れる場合は次を使用します。

```sh
gradle runClient -PvenusTestJei=true
```

`tools/verification/jei-client-smoke.sh`はXvfbを使う検証用です。`run/jeiSmokeServer`に専用の一時ワールドを生成し、停止・保存後、`run/jeiSmokeClient/saves/jei-smoke-world`へコピーしてJEI付き実クライアントで開きます。通常のrun/serverやプレイヤーの既存ワールドを使いません。

スモークは実JEIの登録件数・色違いを含む用途検索・実フォントの本文幅・レイアウト生成を検査し、仕様、接続図、長文の続き、強化の画面を撮影します。結果は`build/reports/jei`へ保存します。自動確認と、人のマウス操作・全リソースパックの目視保証は別です。

## 互換性

機器の保存v16・通信network-3、全136種の4/16幅ケーブル、テクスチャ/モデル/レシピ、ゴーグル、専用タブ、ネットワーク通信規則は変更しません。GUI表示・JEI索引・開発検証のみの更新です。サーバーとクライアントは同じMOD版を使用してください。

検証結果は [NETWORK_JEI_VERIFICATION.md](NETWORK_JEI_VERIFICATION.md) を参照してください。
