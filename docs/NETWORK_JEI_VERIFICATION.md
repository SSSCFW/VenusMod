## 実クライアント起動で見つかった問題

- `e9fd6ff` / run `39373880880`: Build・Native GameTestsは成功。JEIリソースはロードできたが、ワールド参加前でタイムアウトした。JEI全機能成功とは扱わない。
- `923c3e6` / run `39390518755`: 検証専用optionsの初回Accessibility設定と無音出力を補ったが、起動待ちは解消しなかった。
- `ac40de8` / run `39391862475`: JEIランタイム以前の画面名・スクリーンショットを保存し、制限時間で明示的に失敗させる診断を追加。画像と `launch-state.txt` から **BackupConfirmScreen（実験的な設定を使用するワールドの確認画面）** で停止していることを特定した。
- `d3cc726`: 開発モード・専用の `jeiSmokeClient` ディレクトリ・fixture識別子・実験的設定のタイトル・指定の確認ボタンがそろう場合だけ、生成した検証用ワールドを「バックアップを作成して読み込む」操作へ進める。通常プレイ、別ワールド、ダウングレード/復旧などの確認は自動操作しない。

原因確認にはNeoForge1.21.1のWorldOpenFlows/PrimaryLevelDataパッチと、実ゲーム翻訳のボタンキーを用いました。世界データを都合よく書き換えたり、検査を飛ばしてPASSを作ったりする修正ではありません。ワールド開始前でも180秒の期限と画面情報を残すため、以後の失敗を単なる待ち時間として隠しません。

## 範囲

専用GameTestではCreate6.0.10を導入し、JEI本体なしで動作します。実JEIクライアントはJEIを導入し、Createを必須にしない別構成です。JEIなしの専用サーバーとJEIありの実クライアントは区別して記録します。

Xvfb/ソフトウェア描画による自動試験は、実プレイヤーのマウス/キーボード操作、全GUI倍率、全リソースパック、シェーダー併用、実マルチプレイ、大規模TPSの保証ではありません。実クライアントからJEI APIによる画面表示とフレーム画像の確認は実施しました。ゲーム内のJEIショートカットは追加済みですが、その領域を人がクリックする操作試験は未実施です。独立レビュー用サブエージェントは使用せず、差分・例外時の動作・任意依存の自己レビューを行っています。
