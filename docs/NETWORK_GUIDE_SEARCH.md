# 内蔵ガイドの目次と検索

機器GUIの「ガイド」から **「目次・検索」** を開きます。JEIなしでも同じ機能を使えます。

検索対象はガイドの見出し・説明本文・コマンド例・図中の機器名です。日本語、英数字の大文字/小文字、全角英数字を扱います。例えば `VLAN`、`故障`、`port allowed` と入力すると、該当する説明だけが表示されます。空白で区切った単語はすべて含むものを探すAND部分一致です。正規表現・外部検索・実ネットワークへの問い合わせは実行しません。

「全項目」をクリックすると **「この機器」** に切り替わり、現在開いている機器の関連項目に絞ります。関連付けはJEIの公開カタログと接続図の機器に基づきます。項目を隠すだけで、元の23トピック・97手順を削除しません。検索を消して「全項目」に戻すと全項目を参照できます。

項目をクリック、または上下キーで選択してEnterを押すと本文と接続図へ移動します。「目次・検索」へ戻ると検索語と絞り込みを維持します。検索結果は7行ずつ表示し、ホイール・PageUp/PageDown・前後ボタンでも移動できます。0件でEnterを押しても別の項目を勝手に開きません。

Escは目次から本文へ、本文から通常コンソールへ戻ります。検索中に背後のモジュール枠やCLIは操作しません。JEIへのショートカットも、目次・本文・設定フォームの表示中は無効です。ウィンドウを変更した際も検索語を同じ画面内で保持し、通常コンソールの未送信テキストと選択ポート表示も保持します。

検索状態はクライアントの画面だけに保持します。GUIを閉じて開き直した際の保存や、お気に入り登録ではありません。入力上限は96文字で、検索条件が変わった時だけ不変の説明索引を絞ります。サーバーへの通信や機器の設定保存を増やしません。他プレイヤーの設定・所有権・IP一覧を検索する機能ではありません。

機器保存v16、通信network-3、136種類の4/16幅ケーブル、画像・モデル・レシピ・既存プロトコルは変更しません。JEIは引き続き任意です。

検証結果は [NETWORK_GUIDE_SEARCH_VERIFICATION.md](NETWORK_GUIDE_SEARCH_VERIFICATION.md) を参照してください。
