# 王の財宝：火属性・耐久力・壊れた幻想（2026-09-17）

## 戦闘処理

既存の「直撃=5+刀の基礎/エンチャントダメージ+印2/妖刀6」「爆風=3+同補正」を維持する。
火属性は射出した刀のエンチャントから判定し、ダメージが成立した直撃・爆風の敵にLv×4秒の燃焼を与える。
火炎耐性を持つEntityは点火しない。味方・所有者・壁越し対象を除外する既存条件は維持する。
ブロックへの着火、地形破壊、ドロップ破壊は追加しない。

通常の返却時は耐久力Lvに対して1/(Lv+1)の確率で1耐久を消費する。
Lv I/II/IIIなら消費確率は1/2、1/3、1/4。多段命中・爆風の巻き込み人数によって抽選回数を増やさない。
消費が発生しない場合も刀は宝物庫へ返す。最後の耐久を消費した場合は、消滅型の刀は消失し、それ以外は折れた刀で返す。

## 壊れた幻想

王の財宝をメインハンドに持ち、Shift+Fで通常/壊れた幻想を切り替える。通常Fの本数切替は変更しない。
キー自身のCUSTOM_DATAへモードを保存し、custom_model_data=1を同期して赤い専用テクスチャへ切り替える。
準備済みの刀はモード切替時に収納する。この時点では耐久も刀も消費しない。
射出済みの刀は召喚時に記録したモードを維持し、後からキーを切り替えても変化しない。

壊れた幻想では直撃・爆風の計算結果を5倍にし、爆風半径を初期値として2→6ブロックにする。
大きな爆発パーティクルは使うが、実際の地形破壊型の爆発は呼ばない。
着弾した刀は返却せず消滅する。耐久力・耐久無限でもこの生贄は免除しない。
何にも着弾せず時間切れ等で終わった刀は通常と同じ耐久処理で返す。
爆発音は両モードとも着弾地点から1.2Fで再生する。

## 宝物庫の保護状態

カーソルにアイテムを持たずに宝物庫内の刀を右クリックすると、次の順に切り替える。

1. 通常（既定背景）：両モードで使用できる。
2. お気に入り（緑背景）：両モードの射出対象から除外する。
3. 壊れた幻想で使用しない（赤背景）：通常の射出は可能、壊れた幻想では除外する。
4. 通常へ戻る。

1論理スタック全体に適用する。保護は刀自身のCUSTOM_DATAへ保存し、取り出し・再収納後も保持する。
旧SavedDataのFavorite/PhantasmProtectedは刀側に設定がない場合だけ移行する。旧フラグが両方trueならお気に入りを優先する。
準備後の保護変更は射出直前にも再検査し、必要な刀が足りなければ全射出を中止して部分消費しない。
手動の取り出しは可能。満杯で取り出し失敗時に刀を戻す処理でも両方の保護フラグを保持する。

## /giveの直接回収

次tickのインベントリ差分照合と回収予約を廃止する。
CommandEventではgiveの実行コールバックを包むだけにして、解析時には刀を生成・入出庫しない。
実際の実行時に生成した刀を宝物庫へ直接渡すので、SlashBladeの実行時Component更新との一致比較を必要としない。
通常の/giveと/execute ... run giveの子コンテキストを対象にする。
権限、コマンド構文、executeの条件・分岐、キャンセルはBrigadier/NeoForgeの実行経路に従う。

王の宝物庫を持ち、自動回収ONの場合だけ直接収納する。OFFまたは宝物庫未所持なら通常どおり。
宝物庫に入らない本数はインベントリへ、それも満杯なら所有者向けの通常ドロップへ渡す。
既存のインベントリを探索・吸収しない。自動回収をONに切り替えただけでは何も移動させない。
刀以外の/give、上限エラー、回収対象がいないコマンドは元のバニラ実装へ渡す。

## 検証上の区別

純Javaの数式/確率/保護/配達ルールと、パッチ適用プログラムはローカル検査対象。
火属性の実衝突経路、大爆風の範囲、キーの状態は追加GameTestに含める。
完全なNeoForgeビルド、GameTest実行、実クライアントの見え方や音量は別の検証であり、未実行を成功扱いしない。
