# 閻魔刀の次元移動

## 目的と操作

Minecraft 1.21.1 / NeoForge の既存 `feature/venus-hostile-mobs` に、SlashBlade の魔剣「閻魔刀」専用機能を追加する。H（キー設定で変更可）を押して「次元移動」を開く。保存地点と設定はプレイヤーUUIDに紐づけてOverworldのSavedDataに永続化する。刀の判定に表示名は使用しない。

画面左に通過対象、開放方式、秒数、現在位置保存、新規フォルダーを置く。中央には保存地点と現在開いている隙間のタブを置く。フォルダー階層、名前変更、移動、手動順序と名前・保存日時・次元による並び替え、確認付き削除を備える。

## 隙間

地点を選ぶと画面を閉じ、横方向から右への一振り、上から下への一振りを行い、その後に入口と出口を同一サーバーtickで生成する。攻撃演出はダメージ処理を伴わない。入口は目の前、出口は保存した次元・位置。地形の中やワールド境界外へは生成・転送しない。既存ブロックを変更しない。

輪郭は4頂点を持ち辺が内側に曲がるアステロイド曲線。内側にバニラのEnd Gateway描画を使い、両面から見える。左右半幅1.25、高さ半幅1.6ブロックを初期値とする。開閉時は短く拡大・縮小する。

## 通過規則

- 対象: 自分のみ / プレイヤーのみ / プレイヤーと友好MOB / 全て。
- 友好MOB: 敵対カテゴリ・Enemyを除き、攻撃対象や怒り状態がないMOB。
- 開放: 最初の1体が通過して指定秒後 / 生成から指定秒間 / 無制限。秒数1〜180、初期値は自分のみ・最初の通過から1秒後。
- 両側で同じ設定と終了時刻を共有する。通過後に終了時刻を延長しない。
- 到着した対象と同時転送した乗客は、到着した隙間の判定を一度抜けるまで再転送しない。固定時間だけのクールダウンに置き換えない。
- 到着先の隙間が重なっている場合も、その到着状態による即時再転送を抑止する。
- 開いている対は所有者が画面からいつでも閉じられる。閉鎖時に両端と保持チャンクを同時に解放する。

## 実装境界

`YamatoTravelData`: 地点、階層、設定。`YamatoNetwork`: 有界の操作要求と表示状態。`YamatoRifts`: サーバーが管理する対・寿命・通過。`YamatoRiftGeometry` と `YamatoRiftRules`: 描画と接触・時間の共通純粋規則。クライアントのGUI、描画、モーションは専用クラスに分離し、専用サーバーから参照しない。SlashBladeは任意依存を維持する。

開いている対もSavedDataで保持し、再起動後に復元する。転送直後の再ログインでもループしないよう、到着ロックは対とともに保持する。サーバーはプレイヤーの実位置を保存し、移動要求は所有する保存地点IDのみ受け入れる。

## 検証

純粋Javaで輪郭・接触・通過対象・寿命・再進入・整理操作を検証する。GameTestでSavedData、プレイヤー所有権、同一/異次元転送、乗客、閉鎖・解放を確認する。既存の `gradle build` とCreate有効のGameTestを実行する。実際のGUI操作・VMDの見え方・描画最適化Modとの表示はゲーム内検証と区別して報告する。
