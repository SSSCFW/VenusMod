# ネットワークJEI連携 Implementation Plan

> **For agentic workers:** superpowers:executing-plans。既存の承認済み仕様に従ってJEI・機器ガイドを継続する。

**Goal:** アイテムごとの接続手順と仕様をJEIから見つけられ、長い説明が欠けず、実JEI実行環境でも登録と描画を確認できるようにする。
**Architecture:** 不変の純JavaカタログをJEIの入力検索と個別説明へ共有。文字幅による折返しはMinecraft Fontへ委譲し、表示行数でカードを分割する。通常実行はJEI任意のまま、専用プロパティで検証時のみJEI実体を導入する。
**Tech Stack:** Java21 / Minecraft1.21.1 / NeoForge21.1.235 / JEI19.21.0.247。
**Spec:** docs/NETWORK_SYSTEM_SPEC.md のGUI/JEI・接続例・説明・軽量化、およびユーザーのJEI実装継続依頼。

## Global Constraints
- feature/venus-hostile-mobsのみ。既存Build 1.21.1 NeoForgeのみ使用。
- 136種の4/16幅ケーブル、画像/モデル/レシピ、保存v16、network-3、既存ネットワーク挙動を変更しない。
- JEIを必須依存にしない。ゲーム内GUIのガイドを残す。
- 診断用クライアントは専用一時ワールドに接続し、所有者の既存ワールドやOS外部通信を機器機能から操作しない。
