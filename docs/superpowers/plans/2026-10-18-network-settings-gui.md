# ネットワーク基本・ポート設定GUI 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans。承認済み全体仕様の継続実装。

**Goal:** CLIを補完し、機器名・IPv4・GW・DNSと6面ポートのVLAN/速度/媒体をフォームで編集する。
**Architecture:** 設定全体をクライアントへ渡さず、対象範囲の公開フィールドだけを同期する。サーバーは現在値との比較で競合を拒否し、検証したコピーの許可フィールドだけを反映する。モーダル表示中は背後のコンテナ操作を遮断する。
**Tech Stack:** Java21 / Minecraft1.21.1 / NeoForge21.1.235。
**Spec:** docs/NETWORK_SYSTEM_SPEC.md のGUI/マルチプレイ/ポート設定/保存要件。

## 制約・判断

- 作業ブランチfeature/venus-hostile-mobs、既存Build 1.21.1 NeoForgeのみ。main、新規ブランチ・workflowを作らない。
- ケーブル4/16幅・74 PNG・レシピ・機器の保存形式v8は維持する。
- Ruling: 次の単位は操作GUIの拡充とする — プロトコル追加済みの機能を実際に設定しやすくするため。高度プロトコルの専用フォームは対象外。
- Ruling: 対象フォーム単位で現在値比較を行う — 別ポートやACLへの同時編集を上書きせず、同じフォームへの編集/モジュール交換は明示的に拒否する。
- Ruling: 適用はボタンで一括、閉じる操作は保存しない — IPだけ変更されGWが古いといった途中状態を避ける。表示中の未保存入力を周期同期で消さない。
- 新しいネットワーク接続/外部ブラウザーなし。説明は日本語、識別子は英語。
