# 基本設定・ポート設定のフォームGUI

Minecraft1.21.1 / NeoForge。承認済みネットワーク仕様のGUIを拡張し、コマンド入力を補完するフォームを追加します。新しいプロトコルや機器ではなく、既存の永続設定を操作する画面です。

## 開き方

機器を右クリックして、上部の **「設定」** を押します。基本設定のフォームが開きます。**「ポート」** ボタンは選択中のポートを開きます。フォーム上部の基本/P0〜P5のボタンでも切り替えられます。

- 基本: 機器名、端末IPv4、プレフィックス、ゲートウェイ、DNSサーバー。
- ポート: 管理ON/OFF、銅線/光、Access/Trunk、VLAN、Auto/固定速度、L3ポートのIPv4/プレフィックス。

P0北・P1東・P2南・P3西・P4上・P5下は世界方位です。機器の正面を回しても番号は変わりません。

ルーター/L3SWのIPは各ポートで設定します。基本画面の端末IP/GW欄は編集不可です。PCなどの端末は逆に基本画面でIPを設定し、ポート側IP欄は編集できません。DNS欄は数値の仮想IPv4を指定します。IP欄の空欄は未設定を意味します。

速度・媒体・モードはボタンをクリックして切り替えます。速度はそのポートの装着モジュールで利用可能な候補だけを表示し、Autoへ戻すこともできます。光に変更するには対応するポートモジュールが必要です。ONU/OLTの北P0は標準で光対応です。

**速い値を設定しただけでは回線は速くなりません。** ケーブル規格、対向ポート、本体容量、WAN回線の上限は従来どおりです。固定速度が両端で食い違えばLink Downです。高い固定速度のままモジュールを外しても、設定を勝手に下げません。現在のリンク状態とポートの最大対応速度をフォームに表示します。

## 保存と未保存入力

**「適用」** は表示中の1ページだけを一括で検証して保存します。他のページで編集した未保存入力までまとめて送信しません。不正なIPやVLANがあれば全体を拒否し、機器名だけが先に変わることもありません。

周期同期・タブ切り替え・画面サイズ変更に対して、入力途中の値はWidgetとは別の状態に保持します。「戻る」やEscapeだけでは保存しません。入力途中の値は同じ機器メニューを開いている間に限り保持します。メニュー自体を閉じた場合は破棄します。**すでに送信した「適用」は、戻る操作では取り消せません。**

「再読込」は、表示中のページの未保存入力を破棄し、最後にサーバーから受信した現在値へ戻します。適用中は書き換えと再送を止め、対応する応答IDを受信してから保存成功と表示します。100クライアントtick応答がない場合は「応答未確認」とし、勝手に成功した扱いにはしません。再読込で実際の値を確認してください。

フォーム表示中は、背後のインベントリへクリック・ドラッグ・ホイール・数字キー等を流しません。Tabで入力欄/ボタンを移動できます。入力欄でEnterを押すと適用します。

## マルチプレイの同時編集

サーバーは対象ページの現在値と、編集開始時の値を比較します。同じページの値や、ポートの対応速度/媒体条件が変わっていれば、古い画面から上書きせず競合を返します。入力は残るため、値を確認して再読込してください。

別ポート、ACL、DNSレコードなど、対象ページに含まれない設定は、最新の設定を基にして保持します。単一項目ごとの自動マージではなく、**基本ページ/選択ポート単位の比較**です。同じ値に戻った変更まで履歴で検出するロック方式ではありません。

機器名・クライアントDNSだけの変更では転送を切りません。DNSサーバーの変更では自機の名前キャッシュを更新します。IP/GW/ポート変更は既存の局所失効規則に従い、影響する物理網の通信を再確立させます。

## 権限・同期・持ち運び

書き込みは、開いているメニュー、対象機器、所有者/共有権限、距離、生存/観戦状態をサーバーで検証します。`public on`によるサービス公開は設定編集の許可ではありません。CLIと同じプレイヤー/ディメンション共通の要求予算を使い、フォームで上限を回避できないようにしています。

クライアントへは基本・ポートの編集フィールドと表示用の速度上限だけを送ります。**設定全体のエンコード結果、ACL/NAT/BGP規則、所有者/共有UUID、スロットのItemStackをフォームデータには含めません。** 在庫スロットは従来のメニュー同期を継続します。サーバーはクライアントからProfileを丸ごと受け取らず、検証した入力欄だけを適用します。

各フォームのエンコード上限は1024文字、ページ数は基本1+ポート6で固定です。同期はメニューを開いている人に限り、通常は20サーバーtick間隔、変更があったときだけ新しいフォームデータを送ります。適用結果は応答ID付きで返します。

保存形式は**v8のまま**です。機器を採掘しても設定・装着品・故障・所有権を従来どおり保持します。フォームの下書きや保留中の応答IDはワールドへ保存しません。Payload登録のバージョンはnetwork-2へ更新したため、**サーバーと参加クライアントの両方を同じ新版へ更新**してください。

8種類の4/16幅ケーブル、74 PNG、ブロック/アイテムモデル、レシピは変更していません。GUI/JEI共通ガイドに既存の機器アイコンを使う4手順を追加し、17トピック67手順になります。

## 対応範囲

高度なルート/ACL/OSPF/BGP/NAT/DNSレコードの専用フォームは今回含めず、従来CLIと共通ガイドを使います。実ブラウザー・外部ソケットは追加していません。実クライアントでの見た目・操作検証と、純Javaの入力状態/サーバーメニュー検査は区別します。
