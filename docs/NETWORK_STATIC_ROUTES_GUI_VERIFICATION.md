変更前のCLIでStaticRouteCommandTestが「exact route deletion must be supported」に失敗すること、StaticRouteDraftTestがAPI不足でコンパイル失敗することを確認しました。その後回収した実装を反映し、43+96=139検査と全103テストクラスが成功しました。入力拒否、正規化、旧形式重複、64件上限、同値/未存在操作での転送維持、返送経路の必要性を検査しています。

既存JEIスモークに実ルーターの設定画面・ネイティブ入力・追加/削除確認/取消/編集/リサイズ/ガイド往復とサーバー状態の照合を追加しています。16-static-route-added、17-static-route-confirm、18-static-route-deletedを撮影します。
