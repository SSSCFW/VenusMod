## 実配線と認可

NetworkStaticRouteGameTestsは通常の青ケーブルでPC―ルーター―L3スイッチ―サーバーを接続し、実メニューと通常のサーバーtickを使用します。論理リンクや通信成功を注入しません。

- 静的経路なしでは不通。往路だけを設定しても成功せず、戻り経路を設定すると往復が成功する。
- 宛先のホスト部を正規化して保存し、同じ経路の再追加で重複を作らない。
- 権限外・閉じたメニューからの追加/削除を拒否する。
- 個別削除後はその宛先へ届かなくなる一方、別宛先と対向機器の経路を保持する。
- IP、装着モジュール、所有者と既存の経路エンコード/デコードを維持する。

認可にはFakePlayerを使用し、人間同士の実マルチプレイ試験とは区別します。今回の新規GameTestは設定のcodec往復までで、採掘ドロップ試験を新たに追加したという意味ではありません。
