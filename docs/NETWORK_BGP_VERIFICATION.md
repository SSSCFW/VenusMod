# BGP IPv4 検証記録

## ローカルJava21

開始点は `867b409`。コード基準は既存CI `a99776f` のソーススナップショットで、開始点までの差は検証ドキュメントのみです。

BGP CLIの追加前に、公開コマンドと経路交換の契約試験が未対応として失敗することを確認しました。実装後に下記の検査を実行しています。

| 検査 | 結果 |
| --- | --- |
| 公開CLI・eBGP実転送・withdraw | 27検査成功 |
| iBGP NEXT_HOP・属性・NAT/ACL結合 | 50検査成功 |
| 選択・広告・Hold/タイマー単体 | 17検査成功 |
| 誤設定・OSPF下位経路・別物理網との分離 | 29検査成功 |
| v6からの移行・v7保存・不正データ | 19検査成功 |
| ASループ・機器/経路/AS_PATH上限 | 8検査成功 |
| 既存の直結候補列挙の互換性 | 1検査成功 |

新規は合計151検査です。タイマーの蓄積検査は多数tickを進めますが、反復tick数を独立した検査数に加えていません。

## 開発中に検出・修正した内容

NAT装置の自機発BGPまで止める過剰な判定、下位経路の優先度変化で広告を再評価しない問題、BGP追加時に既存の直結候補を1ポートに切り詰める回帰を、失敗テストで再現して修正しました。

既存の「BGPは未実装として拒否する」という検査は、引き続き未対応のIPv6に対象を変更し、未対応コマンドを成功扱いしない検査を維持しました。既存GUIガイドの項目・アイコン検査も残しています。

既存ネットワーク検査（ACL/DHCP、NAT、OSPF、VRRP、STP、局所索引、操作予算）も再コンパイル・実行して成功。ガイドは15トピック・148検査。JDKアセット生成と参照検査は174 JSON・74 PNGで成功しています。

## CI・実ブロック検証

`NetworkBgpGameTests`に、実ブロックと通常サーバーtickによるeBGP経路学習、withdraw、機器故障/Hold満了、修理後の復帰と、`Block.getDrops`による機器設定・装着品・故障・所有権の保存の2件を追加しています。論理リンクや学習経路は注入しません。

## 未実施・範囲

実クライアント目視、JEI画面の実操作、シェーダー併用、実際の複数人の操作、大規模TPS計測は未実施です。独立レビュー用サブエージェントは使わず、差分自己レビューと試験で検査しました。

BGPはIPv4サブセットです。完全な実TCP/BGP形式、IPv6、RR、GR、ECMP等は未対応です。ケーブルの4/16幅、画像とモデル、既存レシピは変更していません。
