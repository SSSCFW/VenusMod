## 開発中に検出・修正した内容

NAT装置の自機発BGPまで止める過剰な判定、下位経路の優先度変化で広告を再評価しない問題、BGP追加時に既存の直結候補を1ポートに切り詰める回帰を、失敗テストで再現して修正しました。

既存の「BGPは未実装として拒否する」という検査は、引き続き未対応のIPv6に対象を変更し、未対応コマンドを成功扱いしない検査を維持しました。既存GUIガイドの項目・アイコン検査も残しています。

最終確認で、旧コンソールヘルプと共通ルーティングガイドに残っていた「BGP未対応」の表示を、回帰検査の失敗で確認してから修正しました。コンソールは現在の共通ヘルプを参照し、説明の二重管理を減らしています。

既存ネットワーク検査（ACL/DHCP、NAT、OSPF、VRRP、STP、局所索引、操作予算）も再コンパイル・実行して成功。ガイドは15トピック・58手順・148検査。JDKアセット生成と参照検査は174 JSON・74 PNGで成功しています。

検証環境: Java21、Minecraft1.21.1、NeoForge21.1.235、Create6.0.10。JEI/SlashBlade本体はこのGameTest環境に含まず、既存のSlashBlade実体依存検査の一部はスキップされています。任意の通常専用サーバースモークテストは今回実行しておらず、GameTestサーバーの起動・実行とは区別します。

`ci-latest` の `VenusMod-1.21.1.jar` が検証対象コミット向けに公開されたことも確認しました。公開時のSHA-256: `ecfffcacee7e28c21c56ef92859c59e88e62f898c5d9a43d593dcb6aee3b9996`。このリリースは後続の成功ビルドで上書きされます。

## 未実施・範囲

実クライアント目視、JEI画面の実操作、シェーダー併用、実際の複数人の操作、大規模TPS計測は未実施です。独立レビュー用サブエージェントは使わず、差分自己レビューと試験で検査しました。

BGPはIPv4サブセットです。完全な実TCP/BGP形式、IPv6、RR、GR、ECMP等は未対応です。ケーブルの4/16幅、画像とモデル、既存レシピは変更していません。
